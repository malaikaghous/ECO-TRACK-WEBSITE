# 🌱 EcoTrack – Daily Eco Habit Tracker

EcoTrack is a modern and responsive web application designed to help users build and track eco-friendly daily habits. The application allows users to monitor their environmental activities, track their progress, and stay motivated to make greener choices every day.

## ✨ Features

* 🌱 Add and track daily eco-friendly habits
* ✅ Mark habits as completed
* 📊 View daily and overall progress
* 🔥 Track your eco-friendly streak
* 🏆 Earn points for completing habits
* 📈 Interactive progress dashboard
* 💾 Save user data using Local Storage
* 🌍 Eco-friendly tips and suggestions
* 📱 Fully responsive design
* 🎨 Modern and user-friendly interface
* ✨ Smooth animations and transitions
* 🔄 Dynamic content updates without page reload

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage
* Responsive Web Design

## 💡 How It Works

1. Open the EcoTrack website.
2. Select or add an eco-friendly habit.
3. Complete the habit during the day.
4. Mark the habit as completed.
5. Your points and progress are updated automatically.
6. Continue completing habits to maintain your eco streak.

## 🎯 Project Goals

The main goal of EcoTrack is to encourage users to develop sustainable habits and become more aware of their daily environmental impact.
